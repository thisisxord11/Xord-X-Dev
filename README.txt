XORD X DEV — STATIC WEBSITE
===========================

RUN THE WEBSITE
1. Extract this ZIP to a folder.
2. Open the folder.
3. Double-click index.html.
4. It should open directly in your browser. No Node.js, npm, build step or backend is required.

TALLY FORM
- Your Tally form is already connected: https://tally.so/r/8No5ex
- The form is embedded in the contact section near the bottom of the page.
- Each “Get Services” button scrolls to the embedded form and passes the selected service as a URL parameter.
- If the embedded form does not appear in a browser, use the “Open Tally form” fallback link.
- Tally needs an internet connection; submissions and notifications are handled by your Tally account settings.

HONEST LIMITATIONS
- The chatbot loads from Botpress and requires an internet connection; test it in a browser to confirm the external bot is available.
- The starter tools create local text drafts; they do not create DOCX/PDF files or call AI.
- A static site cannot securely store secret API keys or run private backend logic.
- Google Fonts need an internet connection; system fallback fonts are included.
- Tally needs an internet connection and a valid public form URL.
